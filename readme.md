# NutriTrack

NutriTrack is a Nutrition, Diet, Activity and Weight Tracking Web App.

## Features

- Personal Profile
- Age, Height, Weight and Sex
- Activity Level
- Daily Nutrition Overview
- Calories Tracking
- Protein Tracking
- Carbohydrates Tracking
- Fat Tracking
- Fiber Tracking
- Calcium Tracking
- Magnesium Tracking
- Iron Tracking
- Potassium Tracking
- Vitamin C Tracking
- Vitamin B12 Tracking
- Vitamin D Tracking
- Omega-3 Tracking
- Breakfast Tracking
- Lunch Tracking
- Snack Tracking
- Dinner Tracking
- Other Meals Tracking
- Daily Activity Tracking
- Steps Tracking
- Workout Tracking
- Weight Tracking
- Weight History
- Delete Food Entries
- Delete Activity Entries
- Date-wise Tracking
- Local Data Storage
- Responsive Design

## Nutrition Goals

Current configured reference goals:

- Calories: 2000 kcal
- Protein: 110–130 g
- Carbohydrates: 270 g
- Fat: 55 g
- Fiber: 20–25 g

## Nutrition Overview

The dashboard shows:

- Today's achieved amount
- Daily goal
- Remaining amount
- Percentage progress
- Progress bar

## How to Run

1. Open the project folder in VS Code.
2. Make sure these files are in the same folder:
   - index.html
   - style.css
   - script.js
3. Open `index.html` using VS Code Live Server.
4. The application will open in the browser.

## Data Storage

This starter version uses browser LocalStorage.

Each browser/device keeps its own data.

For a future public version, authentication and a cloud database can be added so different users can securely store and access their own data.

## Project Files

### index.html
Contains the structure and content of the application.

### style.css
Contains the design, layout and responsive styling.

### script.js
Contains the application logic, calculations, food entries, nutrition overview, activity tracking, weight tracking and LocalStorage functionality.

## Important

The nutrition and energy values in this application are configurable reference values and should not be treated as medical advice.
